# Studies

Recipes for published comparisons. Run them with the study's scripts so settings,
repetitions and reporting match the published protocol.

- [ash-vs-pq](ash-vs-pq): ASH and PQ at matched code sizes on 1M and 6M/10M
  datasets. See [Reproducing ASH versus PQ](../../../../docs/ash-pq-benchmark.md)
  and the results in [ASH performance](../../../../docs/ash-performance.md).
- [ash-vs-pq-single-jvm](ash-vs-pq-single-jvm): the MPNet 10M 2-bit ASH case in
  one JVM, building once and querying with 1 and 8 workers, for the
  [benchmark launcher](../../../bench-profiles/README.md).
