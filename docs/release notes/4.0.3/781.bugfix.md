### Correct Fused PQ Retained Memory Accounting

**Description**

Correct `ramBytesUsed()` for fused PQ sources, byte sequences, and shared on-disk
graph caches. Remove the erroneous four-times multiplier on source byte counts,
include retained buffer wrappers, native heap segment scopes, graph metadata,
cache capacity, and adjacency-array overhead, and count shared backing storage once.
Sizing follows the running JVM's reference sizes, field offsets, headers, and
alignment, including JDK 25 compact object headers.

**How to Enable**

Automatic; no configuration is required.

**Notes**

Reported sizes can increase or decrease, affecting applications that use these
estimates for memory limits or cache sizing. Existing indexes do not require
rebuilding; the on-disk format and search results are unchanged.

Graph memory reporting traverses resident shared objects and uses temporary identity
tracking. Compressor models and worker scratch remain separately accounted. See
[retained memory accounting](../../retained-memory-accounting.md) for the ownership
boundary, reporting cost, and validation details.
