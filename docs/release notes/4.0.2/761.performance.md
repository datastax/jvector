### Batch Native Highway Operations

**Description**

Reduce Java/native calls and temporary allocation during PQ training, PQ encoding,
and NVQ processing. Batch closest-centroid scans and KMeans updates, use lazy
array-backed native views, batch NVQ growth-rate search, and keep cosine results
packed.

**How to Enable**

No new configuration is required. These optimizations apply when the native
provider is selected, which is the default on supported Java 22+ runtimes.

**Notes**

Existing native function signatures and ABI 1 are unchanged. Four additional
native kernels are included in the bundled library; deployments supplying their
own native library must include these kernels. No index-format changes.
