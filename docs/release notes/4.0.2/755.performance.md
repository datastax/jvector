### Avoid temporary SIMD allocations in Panama kernels

Make SIMD species explicit in PQ, NVQ, similarity and shared arithmetic kernels to
avoid temporary vector objects and backing arrays when caller inlining changes.
This addresses severe PQ encoding slowdowns exposed by the vector-access callback.

No configuration is required. Existing arithmetic, APIs and on-disk formats are
preserved. Added computation and allocation regression tests cover the affected
kernels.

Avoid faulty indexed SIMD loads on affected x86 JDK 20 and early JDK 21 runtimes.
