### Extend Native SIMD Coverage for Vector Operations

**Description**

Move minimum and sum reductions, in-place scaling, and vector and scalar
subtraction from Panama Vector API fallbacks to native Google Highway kernels,
using the existing x86-64 and AArch64 ISA dispatch.

Subtraction ranges and input lengths are validated before processing.
Minimum reduction preserves Java’s NaN propagation and signed-zero behavior.

**How to Enable**

These operations use the existing experimental native-vectorization setting.
No new configuration is required.

**Notes**

Hamming distance continues to use the Panama Vector API implementation.
No public API or index-format changes.
