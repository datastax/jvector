### `GraphSearcher` Returns an Empty Result for `topK == 0`

**Description**

`GraphSearcher.search` with `topK == 0` read the empty results queues: with a reranker it threw a
`NullPointerException` from `NodeQueue.rerank`, and with `rerankK == 0` it compared against and evicted stale heap
slots, which could throw on a later `resume` or make the search depend on the previous query. `search` and `resume`
now return an empty result without searching when `topK` (or `additionalK`) is 0, and `NodeQueue.rerank` sends every
candidate to the unused pile when `topK` is 0. See [#811](https://github.com/datastax/jvector/issues/811).

**How to Enable**

No configuration is required.

**Notes**

Callers that short-circuit `k == 0` before calling `search` as a workaround can keep doing so; it is no longer
necessary.
