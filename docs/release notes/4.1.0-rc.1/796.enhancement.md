### BenchYAML: ASH defaults, explicit pipelines and one-JVM experiments

**Description**

BenchYAML's index YAML schema 3 states each pipeline explicitly: index type, construction and
search compression, construction scoring, reranking, query execution (`direct` or `queued`), and
construction and search worker counts. It can also sweep the upper layers' degree separately from
the base layer's. Schema 1 files are still accepted.

- **Defaults.** Without arguments, BenchYAML runs a few small public datasets and prints the key
  results. Compressed dataset defaults now use fused ASH.
- **Results.** Runs report stored-code load and write times and the codes file size. Every console
  and CSV result field is defined in the BenchYAML Guide.
- **Measurement settings.** Run configurations can measure cold queries, and a larger-than-memory
  run configuration is included.
- **One-JVM experiments.** `benchyaml-play.sh` builds the checkout and runs one experiment in one
  JVM from the command line or IntelliJ.

**How to Enable**

Set `yamlSchemaVersion: 3` to use the new fields. See the [BenchYAML Guide](../../benchyaml-guide.md),
the [example pipelines](../../../jvector-examples/yaml-configs/index-parameters/README.md) and the
[benchmark launcher](../../../jvector-examples/bench-profiles/README.md).
