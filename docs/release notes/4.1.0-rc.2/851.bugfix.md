### Concurrent Inserts into Mutable BQ Vectors

**Description**

`MutableBQVectors` could lose codes or undercount when several threads called `encodeAndSet` or `setZero` at
once. Inserts are now thread-safe, as in `MutablePQVectors`. `setZero` now stores a code of the right length
(it was 8× too long), and invalid ordinals throw `IllegalArgumentException`.

**How to Enable**

No configuration is required.
