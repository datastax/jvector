### Faster Exact-Score Search and Build

**Description**

Exact search and graph builds now score a node's unvisited neighbors in one bulk call, four vectors per pass with the
Panama provider, which overlaps their memory loads. This applies to every vector source, including custom ones; the
on-disk graph reads into vectors it reuses instead of building one per read. Scores can differ from one-at-a-time
scoring only in their last bits, as pairwise scores already can between JIT tiers.

New API:

- `RandomAccessVectorValues.similarityTo(query, vsf, nodes, count, results)`, with a default that suits any source.
- `VectorSimilarityFunction.compare(q, targets, count, results)`, with matching bulk methods on `VectorUtil` and
  `VectorUtilSupport`.

**How to Enable**

Nothing to do.
