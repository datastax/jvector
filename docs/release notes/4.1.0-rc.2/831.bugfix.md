### Fused Search with a Score Function from Another View

**Description**

A fused score function (ASH or PQ) created from one `OnDiskGraphIndex` view and searched with another
could pair a node's neighbor scores with another node's neighbor list, changing search results. The
searching view now loads the node's own neighbors. Batch scoring no longer throws `NullPointerException`
in graph builds over 1-bit or non-SIMD streaming ASH vectors, or with `ASHVectors.blockScorerFor(query)`.

**How to Enable**

No configuration is required.
