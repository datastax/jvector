### Faster PQ Query Setup for COSINE and DOT_PRODUCT

**Description**

With the Panama vector provider, building the per-query PQ lookup table for `COSINE` and `DOT_PRODUCT` called a
dot-product routine too large for the JIT to inline for every centroid, even when a PQ subvector was exactly one SIMD
vector wide (4 floats on 128-bit hardware, 8 on AVX2, 16 on AVX-512). That case is now handled directly, with unchanged
results. The native provider and other subvector sizes are unaffected. See
[#815](https://github.com/datastax/jvector/issues/815).

**How to Enable**

No configuration is required.

**Notes**

Building the table for a 1024-dimension index dropped from 281 to 24 microseconds on Apple silicon (4-float subvectors)
and from 97 to 30 microseconds on AVX-512 (16-float subvectors, JDK 25).
