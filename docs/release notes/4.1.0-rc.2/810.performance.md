### GraphSearcher Allocates Its Visited Marker Once per Searcher

**Description**

`GraphSearcher.searchOneLayer` created a `visited::add` method reference for every expanded node and passed it to
`processNeighbors`. The method reference captures only the searcher's final `visited` set, so it is now created
once per searcher instead of once per expanded node. See [#809](https://github.com/datastax/jvector/issues/809).

**How to Enable**

No configuration is required.

**Notes**

This PR originally also hoisted the `NeighborProcessor` and the score function out of the search loop.
[#796](https://github.com/datastax/jvector/pull/796) does that, so this PR now only covers the `visited::add`
allocation that was left over.
