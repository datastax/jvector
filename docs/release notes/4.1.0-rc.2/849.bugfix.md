### Close all thread-local vector copies after a cleanup failure

**Description**

When one vector copy threw during cleanup, the supplier skipped the remaining copies and kept its cache. Closing the supplier now attempts to close every cached copy and clears the cache. It rethrows the first failure with later failures suppressed.

**How to Enable**

No configuration is required.

**Notes**

The supplier creates fresh copies on reuse. If a graph build and its cleanup both fail, the build failure remains primary and the cleanup failure is suppressed. See [#764, section 2](https://github.com/datastax/jvector/issues/764).
