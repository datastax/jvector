### Close all thread-local vector copies after a cleanup failure

**Description**

When one vector copy threw during cleanup, the supplier skipped the remaining copies and kept its cache. Closing the supplier now attempts to close every cached copy and clears the cache. If any copy throws an `Error`, the supplier rethrows the first `Error`. Otherwise, it rethrows the first exception. It retains other failures as suppressed exceptions.

**How to Enable**

No configuration is required.

**Notes**

The supplier creates fresh copies on reuse. If only cleanup fails, the graph build propagates unchecked failures directly and wraps a checked exception in `RuntimeException`. If a graph build and its cleanup both fail, the build failure remains primary and the cleanup failure is suppressed. See [#764, section 2](https://github.com/datastax/jvector/issues/764).
