### Faster Native PQ Graph Builds at Every Subspace Width

**Description**

The native provider scores PQ code pairs in one call, from a copy of the codebooks padded with zeros so odd and mixed
subspace widths run as fast as even ones. Subspaces of 16 floats or more use a centroid-pair table, which is faster
there. Saved and in-progress codes both gain, and Panama is unchanged.

**How to Enable**

No configuration is required.

**Notes**

On cohere-english-v3-1M (128 subspaces of 8 floats), native on-disk builds on GNR (48 cores) took 25-31 s against
40-52 s without this change.
