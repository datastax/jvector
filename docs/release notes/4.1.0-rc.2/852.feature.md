### Streaming BenchYAML Builds with PQ or Full Precision

**Description**

BenchYAML's streaming builds (`construction.streaming: Yes`), which add vectors as they arrive the way a live index is
built, now work with PQ and with no construction compression, not only ASH. A PQ index trains its model first, then
encodes each arriving vector into mutable PQ codes and adds it to the graph; with `refineAfter`, it fine-tunes the
codebook once mid-build, re-encodes the codes so far and rescores the graph's edges. A full-precision index adds each
vector with exact scores. A streamed PQ index keeps its codes beside it on disk and in the saved-index cache, as a
streamed ASH index does.

**How to Enable**

Set `construction.streaming: Yes` with a single `PQ` or `None` construction compression; add `refineAfter: [N]` for
PQ. See the `streaming-pq` and `streaming-fp` examples in `jvector-examples/yaml-configs/index-parameters`.

**Notes**

Streaming times are comparable only with other streaming runs: insert order and threads differ from batch builds.
Cold starts remain ASH-only, and BQ streaming is not supported.
