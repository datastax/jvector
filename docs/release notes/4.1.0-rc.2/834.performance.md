### Cheaper Closest-Centroid Assertion With `-ea`

**Description**

With assertions enabled, `VectorUtil.tryClosestCentroid` rescanned every centroid after each
call, which slowed PQ encoding up to 5x with the native provider. It now checks only the
selected distance, and centroids are checked once when they are built. Runs without `-ea`
are unchanged.

**How to Enable**

No configuration is required.
