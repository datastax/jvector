### Note That `ramBytesUsed()` Can Grow After Load

**Description**

Document that `ramBytesUsed()` counts caches created after loading, such as the PQ
cosine table, so its value can grow while an index is open. A caller that adds
the value when it opens an index must subtract that same value at close, not a
fresh read. See [retained memory accounting](../../retained-memory-accounting.md).

**How to Enable**

No configuration is required.
