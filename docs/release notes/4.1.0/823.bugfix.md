### `neighborOverflow` Values Such as 1.3 and 1.4 No Longer Trip an Assertion

**Description**

Inserting a backlink capped the neighbor list at `M * neighborOverflow` computed in `float`, while the neighbor
arrays were sized from the same product computed in `double`. For overflow factors such as 1.3, 1.4, 1.8 and 1.9 the
`float` product rounds up to the next integer for some `M` (for example 1.4 with `M` = 5, 10, 15, ...), so with
assertions enabled the build failed with "could exceed max overflow degree", and without them a neighbor list could
briefly hold one neighbor more than intended. Both now use the `double` product. See
[#822](https://github.com/datastax/jvector/issues/822).

**How to Enable**

No configuration is required.

**Notes**

The default overflow of 1.2 is not affected.
