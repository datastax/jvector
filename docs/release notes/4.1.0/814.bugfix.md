### GraphIndexBuilder Searches With No Score Floor, So DOT_PRODUCT Vectors Dissimilar to Everything Get Neighbors

**Description**

`GraphIndexBuilder.addGraphNode` and `improveConnections` searched with a score threshold of `0.0f`. That accepts
everything for `COSINE` and `EUCLIDEAN`, but `DOT_PRODUCT` scores are `(1 + dot) / 2`, which is negative for
non-normalized vectors. Every candidate of a vector that is dissimilar to all the others was discarded, so it was
inserted with no neighbors; if it was the entry node, the index was built without any edges and searches returned a
single result. The builder now uses `Float.NEGATIVE_INFINITY`, as `GraphSearcher.internalSearch` already does. See
[#813](https://github.com/datastax/jvector/issues/813).

**How to Enable**

No configuration is required. `COSINE` and `EUCLIDEAN` builds are unchanged.

**Notes**

On ordinary non-unit `DOT_PRODUCT` data recall did not change (20,000 x 128-dimension vectors, recall@10 1.0000 to
0.9993 across four scalings, the same with and without the change). Non-normalized `DOT_PRODUCT` graphs can still be
poorly connected for other reasons.
