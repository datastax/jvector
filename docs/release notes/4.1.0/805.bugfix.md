### Reconnect Nodes Left Unreachable by `GraphIndexBuilder.cleanup()`

**Description**

Neighbor pruning during insertion and `cleanup()` can drop the last in-edge of a node, leaving it
unreachable from the entry node, so no search can return it. The repair that handled this,
`reconnectOrphanedNodes()`, was removed with the hierarchy change in
[#402](https://github.com/datastax/jvector/pull/402). `cleanup()` now restores it for layer 0: once
degrees are enforced, each unreachable node gets an in-edge from the closest reachable neighbor, or
from a search result, evicting that neighbor's worst edge so the degree cap still holds. It repeats
for up to five passes. See [#804](https://github.com/datastax/jvector/issues/804).

**How to Enable**

No configuration is required. It runs inside `GraphIndexBuilder.cleanup()`, and so inside `build()`.

**Notes**

On a 100k-node, 1024-dimension build with M=32, this reduced the nodes unreachable from the entry node
from about 50 to 0, and from 856 to 0 with M=16 and `beamWidth` 200. `cleanup()` took roughly 0.1 to
0.3 s longer in a 1.3 to 1.4 s phase. Upper layers are not repaired. With a very small maximum degree
(M=2) a few unreachable nodes can remain after five passes.
