### BenchYAML: ASH defaults, explicit pipelines and one-JVM experiments

**Description**

BenchYAML's index YAML schema 3 states each pipeline explicitly: index type, construction and
search compression, construction scoring, reranking, query execution (`direct` or `queued`), and
construction and search worker counts. Compressed dataset defaults now use fused ASH, and
`benchyaml-play.sh` builds the checkout and runs one experiment in one JVM from the command line or
IntelliJ.

**How to Enable**

Set `yamlSchemaVersion: 3` to use the new fields. See the [BenchYAML Guide](../../benchyaml-guide.md),
the [example pipelines](../../../jvector-examples/yaml-configs/index-parameters/README.md) and the
[benchmark launcher](../../../jvector-examples/bench-profiles/README.md).
