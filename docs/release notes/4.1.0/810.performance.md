### GraphSearcher Allocates Its Per-Neighbor Callbacks Once per Layer Search

**Description**

`GraphSearcher.searchOneLayer` created a `NeighborProcessor` lambda and a `visited::add` method reference for every
expanded node. Both capture only state that is fixed for the whole call, so they are now created once per layer
search. See [#809](https://github.com/datastax/jvector/issues/809).

**How to Enable**

No configuration is required.

**Notes**

With a reused `GraphSearcher` these two objects were about 92% of the allocation under `GraphSearcher.search`
(7,550 bytes per query, 2,936 after) on a 20,000 x 1024-dimension cosine graph. No change in throughput was
measured; the benefit is lower allocation volume for callers that pool searchers.
