### GraphIndexBuilder Uses No Rerank Floor in the Layer-0 Resume, and `improveConnections` Is Tested

**Description**

Follow-up to [#814](https://github.com/datastax/jvector/pull/814). The layer-0 `resume` in
`GraphIndexBuilder.addGraphNode` still passed a rerank floor of `0.0f`. A score provider with a reranker only reranks
candidates at or above the floor, so with a custom provider and non-normalized `DOT_PRODUCT` vectors, a node
dissimilar to everything got only its single best candidate as a neighbor. The floor is now `Float.NEGATIVE_INFINITY`.
The built-in build score providers have no reranker and were not affected. A test now also covers `improveConnections`
on an upper-layer node whose similarities are all negative. See [#817](https://github.com/datastax/jvector/issues/817).

**How to Enable**

No configuration is required.

**Notes**

Only builds with a custom `BuildScoreProvider` that supplies a reranker, and `DOT_PRODUCT` on non-normalized
vectors, change.
