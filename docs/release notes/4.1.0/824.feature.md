### Adaptive Beam Search Termination (Experimental)

**Description**

`GraphSearcher` can stop the base-layer search by distance instead of by beam width, using the stopping rule of
[Adaptive Beam Search](https://arxiv.org/abs/2505.15636). The search stops once `rerankK` results are closer to
the query than the best remaining candidate by a factor of `1 + gamma`, so easy queries stop early and hard ones
search longer. On 100,000 1024-dimension text embeddings it matched the recall of beam widths 100 to 250 while
visiting 14-19% fewer nodes and answering 17-21% more queries per second. p99 latency rose, because the hardest
queries get more work.

**How to Enable**

Pass an `AdaptiveTermination` to the new `search` overload; `rerankK` is then the number of results to wait for:

```java
var termination = AdaptiveTermination.of(VectorSimilarityFunction.COSINE, 0.05f);
SearchResult r = searcher.search(ssp, topK, topK, 0f, 0f, Bits.ALL, termination);
```

The benchmark grid takes an optional `search.adaptiveGamma` list, and `RecallWithRandomVectorsBenchmark` a `gamma`
parameter.

**Notes**

Useful values of `gamma` are small and depend on the data (0.02 to 0.07 spanned recall@10 0.95 to 0.996 on the
embeddings above). Without a termination, search behaves exactly as before. The rule assumes unit-length vectors for
DOT_PRODUCT.
