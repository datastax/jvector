### `GraphSearcher.search` With `topK == 0` No Longer Throws When a Reranker Is Set

**Description**

`GraphSearcher.search` with `topK == 0` and a score provider that has a reranker threw a `NullPointerException`
from `NodeQueue.rerank`: with nothing in the reranked queue it read a stale heap slot, treated that slot's node as
an eviction candidate and unboxed a score that was never recorded. `rerank` now sends every candidate to the unused
pile when `topK` is 0, and the search returns an empty result. See
[#811](https://github.com/datastax/jvector/issues/811).

**How to Enable**

No configuration is required.

**Notes**

Callers that short-circuit `k == 0` before calling `search` as a workaround can keep doing so; it is no longer
necessary.
