### `MutablePQVectors` Updates Its Vector Count Without a Capturing Lambda

**Description**

`MutablePQVectors.encodeAndSet` and `setZero` raised the vector count with
`updateAndGet(current -> max(current, ordinal + 1))`, a lambda that captures `ordinal` and so may
allocate on every call. They now use `accumulateAndGet(ordinal + 1, Math::max)`, which passes the
value as an argument and needs no allocation. The result and its atomicity are unchanged. In JMH
runs on JDK 22 and 25, the JIT already removed the old allocation once the code was warm, so
`encodeAndSet` time and allocation are unchanged in steady state.

**How to Enable**

No configuration is required.
